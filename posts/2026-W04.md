## Code Overview
- nonarithmetic_arithmetic_func.py & and call stack note/example .jpg files
  - This function idea originally came from the "Automate the Boring Stuff with Python Workbook" by Al Sweigart
  - Here, the goal of this mini project/challenge was to create a function that could add two numbers, with the limitation being the only mathematical operation you could use was from the defined plus_one() function provided.
  - From the add() function, you were then asked to create a multiply() function with add() function.
  - I ended up taking this a step further by creating an exponent() function with the multiply() function
  - With this program in place, I took it upon myself to do a deep dive on the call stack concept--notes in the .jpg files provided 

- file_1.py & file_2.py
  - I used these files to review the dunder variables __name__ and __file__
  - In file_1.py, I ran into a situation where the directory I was working in was different than the file path to the Week_04_Notes.txt that I wanted to open and use in the file. So as a "workaround", I used the __file__ dunder variable and the os.path.basename() method along with string slicing and concatenation to derive the appropriate absolute file path for the file.
  - You can see that there are three versions I went through for deriving the absolute file path. The first one used explicit variable for each of the steps throughout the process, while versions 2 and 3 used less and less variables. I ended up opting to go with version 2 since I believe it was the most understandable/readable of the three and was a happy medium.
  - After the obtaining the file path and printing my notes from the text file, I used a 'if __name__ == "__main__":' clause which prints out a different output whether this file is ran directly or as a module
  - file_2.py has imports file_1.py where it can be ran as a module
 
- tick_tock_print.py
  - This was another mini-project from Al Sweigart's workbook where the challenge was to research the time.sleep() function and create a function that alternates printing "tick" and "tock" every second.
